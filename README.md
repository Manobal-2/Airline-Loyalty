
# Airline Loyalty Behavioral Intelligence System

This project predicts airline customer churn, segments users behaviorally, and recommends retention strategies using machine learning and analytics.

## Features

- Churn prediction
- Behavioral segmentation
- Retention recommendation engine
- Streamlit dashboard
- SHAP explainability
- Leakage-safe modeling

## Run

pip install -r requirements.txt

streamlit run app/streamlit_app.py
